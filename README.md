# MovieMingle

Welcome to the MovieMingle project! This is a comprehensive movie website where users can watch free, high-quality movies. The project leverages various modern technologies to provide a seamless user experience.

## About

MovieMingle is designed to offer users a rich movie-watching experience with an extensive library of high-quality movies. Users can easily browse, search, and watch movies without any cost.

## Technologies Used

- **Spring Boot**: For creating the back-end services and REST APIs.
- **Thymeleaf**: For server-side rendering of web pages.
- **MySQL**: For managing the database of movies and user information.
- **JavaScript**: For dynamic interactions on the client side.
- **CSS**: For styling the web pages.
